# AI Disclosure
Coding agents that use LLMs are used in this project to create code tests, write and revise documentation professionally, and run code reviews/suggest optimizations, bug fixes, and improvements. And overall, deliver a better quality of product than I alone, with the time I have, could deliver.

That being said, that doesn't mean I encourage straight up throwing your LLM at the codebase and afterwards just giving back whatever it does. If you are going to use LLMs to contribute to the project, please please please review whatever code your agent writes instead of just adding slop. Test it. Make sure stuff works. Add your own touch to things...

If you have a problem with the usage of Generative AI, well, consider yourself forewarned.
